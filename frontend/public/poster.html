1. Introduction & Problem Context
MOTIVATION

Modern enterprise ransomware strains (e.g., LockBit 3.0, BlackCat/ALPHV, Conti) bypass static hash-matching antivirus engines by employing runtime binary polymorphism and API unhooking. These payloads execute high-throughput encryption bursts exceeding 1,800 IOPS, irreversibly encrypting local user documents within 45 seconds before cloud SOC telemetry alerts trigger.

SENTINEL // EDR resolves this architectural latency vulnerability via an autonomous, sub-kernel behavioral detection core executing directly at the filesystem boundary. By correlating Shannon byte entropy, deceptive canary honeypot tripwires, file rename velocity, and process lineage ancestry in real time, SENTINEL neutralizes zero-day threats in sub-11ms latency with zero user file loss.

2. Mathematical Formulation
ALGORITHM

Let file byte stream B = {b1, b2, ..., bN} where bi ∈ [0, 255] with probability distribution p(bi) = count(bi) / N:

EQUATION 1: SHANNON BYTE ENTROPY SPECTRUM
H(B) = - ∑i=0255 p(bi) · log2 p(bi),   0.0 ≤ H(B) ≤ 8.0 bits/byte

Plaintext assets span H ∈ [3.2, 5.4]; modern ciphers (AES-256-GCM, ChaCha20) converge to asymptotic ceiling H → 7.95 ≈ 8.00.

EQUATION 2: MULTI-FACTOR BEHAVIORAL RISK SCORE (RS)
RS(t) = we·σH(Ht - θH) + wv·(Vwrite/Vmax) + wc·Ctrap(t) + wp·Pancestry

Weights: w_e = 0.35, w_v = 0.25, w_c = 0.25, w_p = 0.15 (∑ w_i = 1.0).

EQUATION 3: DETERMINISTIC THREAT CONTAINMENT DECISION RULE
Action(t) = FREEZE_AND_ISOLATE(PID)   when RS(t) ≥ τcrit = 75

5. Cyber Security & Enclave Integrity
SECURITY

As engineered by the Department of Cyber Security, Malla Reddy University, SENTINEL operates under strict Zero-Trust kernel isolation:

• Zero-False-Positive Heuristic Filter: Benign bulk compression (7-Zip, WinRAR) is distinguished from ransomware encryption via sliding-window byte frequency variance and code-signed process white-listing.

• Driver Self-Defense & ACL Locks: The kernel minifilter enforces unkillable process states, preventing adversary scripts from executing taskkill /F or driver unloading.

• Immutable Forensic Event Chain: Every telemetry record is hashed via SHA-256 and chained into an append-only evidentiary audit log.

12. Architecture & Code Audit
ENGINEERING RIGOR
